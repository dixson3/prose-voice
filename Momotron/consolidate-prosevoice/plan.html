Consolidate pv-prosevoice and pv-preflight into one prosevoice skill with shared Python support, strict layered configuration, explicit legacy migration, and validated source and wheel installations.

Plan

Remove sibling-skill and duplicate resolver dependencies while preserving editorial behavior and providing a safe explicit transition.

Include

  • One skill, Python package and resource-aware launcher/console command.
  • Strict shared configuration, independent guides and additive policy.
  • Explicit migration, safe rule replacement and interruption recovery.
  • Editorial regression, docs, scratch skill install and wheel checks.

Exclude

  • Editorial redesign, new writing features and runtime compatibility.
  • Changes to momotron, operator-installed tooling or frozen history.
  • Real-project migration, global installs, product commits, push and publishing.

Success criteria

  • package-config One resource-aware package and thin launcher implement strict tiered configuration with provenance and independently resolved guides. (foundation, integration, acceptance)
  • preserved-semantics Editorial authority, all 12 artifact routes, READY source/optional-visual checks, premise fingerprints and additive Harper policy are preserved without legacy sibling imports or lookup. (consolidate, acceptance)
  • explicit-migration Preview writes nothing; apply preserves source data, effective guidance, policy and visual decisions, safely switches recognized rules, and fails closed on conflicts with idempotent interruption recovery. (migration, acceptance)
  • distributions Installed wheel and scratch single-skill installs work from unrelated cwd with isolated home/XDG and no legacy siblings; live docs match the implemented contract. (integration, acceptance)
  • bounded-authority Operator tooling, reference repository and frozen history stay unchanged; completion reports verification and limitations without implied publication or real-project migration. (acceptance)
